Chrome extension version

The same bot as a Chrome extension: click its toolbar icon and chat in a small popup, answered by the free web gateway — no key needed. Download the extension files, unzip, then in Chrome open chrome://extensions, turn on Developer mode, choose Load unpacked and select the unzipped folder.

The extension saves nothing either — close the popup and the conversation is gone. It talks only to text.pollinations.ai, the same free gateway this page uses.

How the providers answer

  • Free web gateway (text.pollinations.ai) — no key, no sign-up. It is a shared public service, so it can be slow or throttled at busy times.
  • LLM7 — works with no key on a shared anonymous daily quota; when that quota runs out, Auto moves on to the gateway.
  • Groq, OpenRouter, Gemini, Mistral — need your own free API key, pasted in Settings. Each key is sent only to its own provider.
  • Ollama and Jan — free and fully local, but only reachable when they are running on the device viewing this page.
  • Images — generated through image.pollinations.ai. A watermark or a slower model can appear on the free tier.

Settings

Keys are kept only in this open page and sent only to their own provider. Reload the page and every key here is cleared.

Long memory Stored on this device

Off by default. If you turn it on, the bot remembers facts you give it — your name, what you like, how you want answers — and uses them in later chats. Memory is stored only in this browser, on your own device (localStorage). It is never sent to any server of ours — there is none — and it is only included in a chat when you send a message, as part of that message's context to the provider you chose. Chats themselves still vanish on reload; only these memory facts stay, and only while memory is on.
